# Monos — Releases

Installer downloads for **Monos**, the studio pipeline app. This repository holds
release builds only; the source is private.

- Grab the latest installer from the [Releases](../../releases) page
  (`Monos_Setup_<version>.exe`).
- Monos checks this repository on launch and offers in-app updates
  (Settings › Updates).

Release tags follow the app version (`v26.18.2`, ...). Each release ships one
Windows installer asset; the release notes are what the in-app update dialog
shows.
